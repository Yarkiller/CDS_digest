## Decision: global base rule, not a per-button class

Tailwind CSS v4 no longer applies `cursor: pointer` to `<button>` by default, and the repo only added the explicit `cursor-pointer` class to two modal close buttons. Roughly a dozen Phase 14 controls (per-row «Сделать ready», toolbar buttons, «Превью материала», footer buttons, modal retry/confirm buttons) lack it. A single base rule `button:not(:disabled) { cursor: pointer }` in `@layer base` fixes all of them (and future buttons) in one place, while `:not(:disabled)` preserves `disabled:cursor-not-allowed` / the native default on disabled controls. The two existing explicit `cursor-pointer` classes remain harmless.
