## Typography

Reuse the locked type scale. Phase 22 **new** markup declares **exactly 3 sizes** and **exactly 2 weights** (400 + 600). No fourth size in new chrome.

| Role | Token / utility | Size | Weight | Line Height | Used for |
|------|-----------------|------|--------|-------------|----------|
| Heading (active section) | `--text-h1` / `text-3xl` | clamp 2→3rem | **600** | 1.1 | Active in-page tab label — replaces former page H1 visual weight (D-08) |
| Heading (inactive section) | `--text-h1` / `text-3xl` | clamp 2→3rem | **400** | 1.1 | Inactive in-page tab label — same size, quieter weight + muted ink (D-08 «quieter») |
| Body | `--text-body` / `text-base` **or** existing `text-sm` on select | **1rem / 0.875rem** as used by shell controls | **400** | 1.5 | Narrow `<select>` options/control text |
| Label | `--text-overline` / `text-xs` | 0.75rem (12px) | **600** | 1.4 | Eyebrow **«Админ»** in `AdminLayout` (`uppercase tracking-wide text-muted`) |

**Size count for Phase 22 new markup:** Heading · Body · Label = **3**. Inactive and active tabs share the Heading **size** token (weight differs — still only 2 weights).

Weights: **400 regular** + **600 semibold** only in new Phase 22 chrome.
Exception: existing `font-medium` (500) on shared controls (e.g. UnsavedChangesDialog leave button) — **reuse only**; do not expand.

**Removed from child pages (D-06):** the page-level `<h1>` on `AdminDigestPage` («Shortlist дайджеста») and `AdminPipelineConfigPage` («Конфиг пайплайна»). Hierarchy moves to the active tab. Pipeline page **keeps** the existing body-size hint **«Просмотр и правка без запуска пайплайна»** under the layout chrome. Digest page content starts at its existing section/empty-state headings (`h2` etc.) — no duplicate display title above content.

## Color

Locked OKLCH palette. 60/30/10 discipline mapped to existing tokens. Do not add hues.

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--color-paper` | oklch(97% 0.012 95) | Page surface under layout + Outlet |
| Secondary (30%) | `--color-paper-2` / `--color-rule` | oklch(93.5% 0.018 95) / oklch(84% 0.018 95) | Optional quiet rule under the tab row (`border-b border-rule`); select border |
| Accent (10%) | `--color-accent` | oklch(52% 0.13 278) | See reserved list |
| Destructive | `--color-danger` | oklch(48% 0.15 25) | **Not** used by Phase 22 chrome; leave dialog is non-destructive confirm (Phase 19) |

**Accent (`--color-accent`) reserved for — explicit list:**
- AppShell «Админ» **active** pill (`bg-accent text-accent-ink`) when pathname matches `/admin/*` (D-09) — existing shell treatment
- **Active** in-page tab underline (`border-b-2 border-accent`) and active tab ink (`text-ink`, not accent fill — underline carries accent)
- Focus rings on tab `NavLink`s and the narrow `<select>` (`outline-accent` / existing `:focus-visible`)
- Unchanged Phase 19 leave primary **«Уйти без сохранения»** (solid accent) — reuse only

**Not accent:**
- Inactive tab text (`text-muted` or `text-ink-2`)
- Eyebrow «Админ» (`text-muted`)
- Narrow `<select>` chrome (`border-rule`, ink text)
- AppShell inactive pills (unchanged)

**Pill vs underline (D-05):** AppShell keeps `rounded-full` accent pills. In-page tabs must **not** use pill/`bg-accent` fills — underline only — so the control reads as in-page section switch and honours 16-UI-SPEC «no second navigation bar».

## Page & Component Contracts

### AppShell (ADUX-12, D-09, D-10)
- **Remove** the admin-gated `NavLink` **«Пайплайн»** (`to="/admin/pipeline"`).
- Keep a single admin-gated `NavLink` **«Админ»** with `to="/admin/digest"` (fixed entry).
- Active matching: treat as active when the location is under `/admin` (any `/admin/*`) — e.g. `NavLink` `className` / `isActive` without `end`, or equivalent pathname prefix check. Digest, pipeline, and materials preview all light the pill (D-09, D-11).
- Shell `aria-label="Основная навигация"` unchanged. Pill `linkClass` visual language unchanged.
- Employee: still zero admin shell links.

### Route tree (`App.jsx`, D-01…D-04)
- Nest under existing `RequireAuth` → `AppShell`:
  - Parent route element: **`AdminLayout`** wrapping children:
    - `admin/digest` → `AdminDigestPage`
    - `admin/pipeline` → `AdminPipelineConfigPage`
  - Sibling (no tab-bar): `admin/materials/:id` → `MaterialPage preview` (unchanged).
- **Do not** add `/admin` index or redirect.
- Paths `/admin/digest` and `/admin/pipeline` stay byte-identical for bookmarks and tests.

### AdminLayout (D-01, D-05…D-08, D-12, D-16…D-19)
- New component (suggested: `web/src/components/AdminLayout.jsx`).
- Structure (top → bottom):
  1. Eyebrow **«Админ»** (`text-xs font-semibold uppercase tracking-wide text-muted`)
  2. Section switch:
     - **`sm` and up:** `<nav aria-label="Разделы админки" data-testid="admin-section-nav">` with two `NavLink`s — **«Дайджест»**, **«Пайплайн»**
     - **below `sm`:** hide the `nav` row; show native `<select data-testid="admin-section-select" aria-label="Разделы админки">` with the same two options; `onChange` → `navigate(path)` (D-19) so Phase 19 `useBlocker` still fires
  3. `<Outlet />` for the child page
- Underline tab visuals:
  - Row: `flex` gap `--space-2` / `gap-2`; optional full-width `border-b border-rule` behind the row
  - Active: `text-3xl font-semibold text-ink border-b-2 border-accent` (and cancel the row rule collision — active border sits on the shared baseline)
  - Inactive: `text-3xl font-normal text-muted` (or `text-ink-2`) with `border-b-2 border-transparent`; hover may darken ink only — **no** pill fill
  - Each link: `inline-flex min-h-11 items-end` (or equivalent) so the 44px target holds while the underline sits on the baseline
- Select visuals: `min-h-11 w-full max-w-sm rounded-xl border border-rule bg-paper px-3 text-base text-ink` (or existing form control classes); selected value reflects current route
- `data-testid` recommendations: `admin-section-nav`, `admin-tab-digest`, `admin-tab-pipeline`, `admin-section-select`

### Child pages — drop H1 / duplicate eyebrow (D-06)
- `AdminDigestPage`: remove every page-level H1 **«Shortlist дайджеста»** and the duplicate eyebrow when the page is under `AdminLayout`. Content / empty / success blocks keep their existing `h2` copy.
- `AdminPipelineConfigPage`: remove every page-level H1 **«Конфиг пайплайна»** and the duplicate eyebrow on ready/loading/error branches that currently inline them. Keep hint, editor, toolbar, empty/error panels, and Phase 19 guard wiring unchanged.
- Early `ForbiddenPage` return: layout chrome may still wrap the outlet (nested-outlet pattern). No special hide-tabs carve-out this phase.
- Materials preview: **no** `AdminLayout`; no tab-bar; shell «Админ» still active (D-11).

### Dirty guard interaction (D-13…D-15, D-19)
- Tab `NavLink` click and select `navigate()` are ordinary SPA navigations — **no carve-out**.
- Dirty YAML on pipeline → leave toward digest (or any other in-app target) opens existing `UnsavedChangesDialog`.
- Playwright journey (D-14): dirty editor → in-page **«Дайджест»** → modal → **«Остаться»** keeps draft + `/admin/pipeline`; **«Уйти без сохранения»** lands on digest. Optionally mirror with narrow select in a separate assertion if feasible; select path must not bypass the guard.
