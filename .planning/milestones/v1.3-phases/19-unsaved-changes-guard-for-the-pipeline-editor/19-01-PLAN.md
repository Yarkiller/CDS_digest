# Phase 19 Plan 01 — Tracer: `App.jsx` on a data router, behaviour-preserving (ADUX-09 criterion 4 / D-09)

<objective>
Lead the phase with the thinnest change that touches every layer this phase will modify: the routing backbone. Replace the declarative `<BrowserRouter>` + `<Routes>` JSX tree in `web/src/App.jsx` with a single module-scope `createBrowserRouter([...])` instance rendered through `<RouterProvider>`, preserving every route, the pathless `RequireAuth` + `AppShell` layout route, the `index` route, and the `*` -> `/` `Navigate` catch-all verbatim, and adding no `errorElement`.

Purpose: `useBlocker` (Plan `19-02`) calls the data-router context and throws when it is absent; the declarative router supplies only Navigation/Location context (PITFALLS Pitfall 4). The migration is therefore a hard prerequisite for the guard, and it is a pure refactor with an existing, broad Playwright contract — so it ships as its own plan, proven green BEFORE the guard is wired, so that a later `useBlocker` throw can never be misattributed to the router swap (D-09; PITFALLS Technical Debt Patterns row "Add the guard mechanism and the router migration in one plan" = **Never**).

**Tracer shape and the stated TDD exception (recorded, not self-authorised):** the migration cannot exist in a partially-migrated state — the router object replaces the whole JSX tree at once — so the tracer's "one path" is the whole app rendered through the new router, and its end-to-end verify is the existing full `web` Playwright suite. Because this is a behaviour-preserving refactor, there is deliberately NO new RED test: `tdd.mdc`'s exception for refactors applies, and the gate is the recorded Wave-0 baseline count re-asserted after the refactor (CONTEXT D-09, RESEARCH § Project Constraints).

**Reversibility note (no `checkpoint:decision` inserted, deliberately):** D-09 is rated `costly` — reverting replaces the route object with the JSX tree and touches the shell/layout wiring. The rating is recorded on the implementing task; it is not gated, because the user already locked this door in `19-CONTEXT.md` and `planner-reversibility.md` names "gating a decision already made" as the anti-pattern.

Output: `web/src/App.jsx` migrated to `createBrowserRouter` + `RouterProvider`, with the full `web` Playwright suite green at the recorded baseline count.
</objective>
