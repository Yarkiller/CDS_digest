# Plan 28-01: Prove the streamed DeepSeek ingest on a live long video

**Phase:** 28 — Live proof — streamed DeepSeek ingest
**Requirement:** ING-09
**Context:** `28-CONTEXT.md` (D-01…D-09)
**Nature:** proof + one rider fix. No adapter change, no retry layer, no timeout retuning.

## Goal-backward

`ING-09` is true only if a real long video traverses the **streamed** DeepSeek path and lands as a
draft + pending shortlist row, with the elapsed evidence recorded and the operator preconditions
written down. Everything below exists to make that observable rather than asserted.

## Must-haves

| # | Truth | How it is proven |
|---|-------|------------------|
| 1 | A >10 min video runs end to end through `stream=True` | `stage=llm elapsed_ms` in the `--debug` log plus exit 0 |
| 2 | The run creates a NEW material, not an idempotent re-hit | `already_saved: false` and a `youtube_video_id` that was absent from `materials` before the run |
| 3 | `materials.status='draft'` for that video | read-only query on `materials` by `youtube_video_id` |
| 4 | A `pending` shortlist row exists and is tied to it | read-only query on `digest_shortlist_items` by `material_id` |
| 5 | No `APIConnectionError` / `network_error` anywhere | scan of the captured run log |
| 6 | Another operator can repeat it | the runbook block in the summary: env file, proxy precondition, the `--template` flag, the video |
| 7 | FU-27-01 is closed | Playwright case that fails before the fix and passes after |

## Tasks

### Task 1 — Pre-flight (no code)

1. Confirm the video is longer than 10 minutes and has `ru`/`en` captions, and that its id is absent
   from `materials` (unique `youtube_video_id` ⇒ a re-run would prove nothing).
2. Confirm the transcript fits `MAX_TRANSCRIPT_CHARS` (80 000) so the run cannot die on the budget gate
   instead of the LLM stage.
3. Confirm the network path: DeepSeek reachable **directly**, YouTube reachable **only through
   `YOUTUBE_PROXY_URL`**. A blocked direct TLS to YouTube must be recorded as a precondition, not
   mistaken for a streaming failure.
4. Confirm `--template` is required by the CLI (it is) so the evidence uses the command that actually
   runs.

### Task 2 — The live run (no code)

Run with `--debug` and a wall-clock around it, capturing the whole thing to
`evidence/ingest-run-1.log`:

```
uv run --env-file ./ingestion-service/.env ingest "https://www.youtube.com/watch?v=HR7hD8TO4Z8" --template lecture --debug
```

Assert on the **printed ids**, not on the presence of `✓ saved`.

### Task 3 — Database read-back (no code)

Read `materials` by `youtube_video_id=HR7hD8TO4Z8` and `digest_shortlist_items` by the resulting
`material_id`. Record actual values.

### Task 4 — FU-27-01 (TDD, rider)

1. **RED:** add `an empty header submit replaces the history entry` — from a settled `/knowledge?q=RAG`,
   a whitespace-only header Enter must leave `history.length` unchanged and Back must leave `/knowledge`.
   Run it; it must fail on the length pin.
2. **GREEN:** `SearchPill.jsx` empty branch → `navigate('/knowledge', { replace: true })`.
3. Re-run the case, then `tests/knowledge.spec.js`, `tests/web-app.spec.js`, `npm run test:js`.
