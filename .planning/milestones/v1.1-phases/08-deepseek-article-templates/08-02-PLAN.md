## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenAI exception → ArticleError | SDK objects can echo the prompt in str() and body. Only status_code, code, type, and the class name may be read |
| ArticleError → IngestError.to_dict() | Operator JSON. message and context are an allowlist |
| Failed process → caller | No ArticleDraft leaves the function |
