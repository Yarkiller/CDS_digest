<threat_model>
ASVS L1 · block_on=high

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Transcript text → DeepSeek chat API | Untrusted captions become prompt content. This plan sends them only as the user message of an injected client |
| Settings / process env → client factory | API key and base URL are read only in Settings.from_env. Adapters never see os.environ |
| Model JSON → ArticleDraft | Untrusted model text. Only a JSON object with three non-blank strings becomes a draft |
| Factory errors → caller | ConfigurationError must not echo the API key |

A blank key raises ConfigurationError before AsyncOpenAI is constructed, and the message has no key material. No VITE_ name. Runbook in 08-04 documents names only (ASVS V14) |
