<threat_model>
ASVS L1 · block_on=high

### Trust boundaries

| Boundary | Description |
|---|---|
| `MaterialDraft` → RPC params | Untrusted `youtube_video_id`, slug, and title are passed as parameters to a typed Postgres RPC. No string interpolation. |
| `supabase` SDK → adapter | SDK exceptions may contain raw Postgres text; only reason code and allowlisted context are forwarded. |
| RPC grants | Execute is restricted to `service_role`; `anon`/`authenticated` cannot call the write RPC. |

### STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation plan |
|---|---|---|---|---|---|
| T-09-09 | Information disclosure | Adapter error context | HIGH | mitigate | `SUPABASE_SECRET_KEY` is never read by the adapter. Raw exception strings and Postgres messages are not forwarded; only `video_id`, `slug`, `batch_id`, and `reason` are allowed in mapped context. |
| T-09-10 | Injection | `persist_draft_and_enqueue` parameters | HIGH | mitigate | Use named RPC parameters only. The function uses `INSERT ... VALUES (...)` with typed parameters; no dynamic SQL concatenation of `youtube_video_id` or slug. |
| T-09-11 | Elevation / RLS bypass | RPC grants | HIGH | mitigate | `security invoker`; execute revoked from `public`/`anon`/`authenticated`; granted only to `service_role`. Service role bypasses RLS, but the adapter uses a key held only by the operator CLI. |
| T-09-12 | Tampering / race | Persist + enqueue | HIGH | mitigate | Single PL/pgSQL transaction: `ON CONFLICT (youtube_video_id) DO NOTHING`, material lookup, batch selection/creation, and shortlist insert are atomic. Any exception rolls back to zero rows. |
</threat_model>
