# Phase 9 Plan 01 — Amend Phase 8 contract with `roles`

## Objective

Promote `RoleKind` to a first-class field on `ArticleDraft` and `MaterialDraft`, teach both prompt templates to ask the LLM for audience roles, and make the DeepSeek adapter normalize the LLM reply to a valid non-empty role list. This is the Phase 9 tracer: a stubbed LLM JSON with roles must round-trip through validation, assembler, and into a `MaterialDraft` with a non-empty `roles` list.

Purpose: Lock the audience-role dimension before any persistence work, so the persist port receives a complete `MaterialDraft`.
Output: `RoleKind`, `ArticleDraft.roles`, `MaterialDraft.roles`, updated templates, DeepSeek adapter normalization, and updated fakes/tests.
Scope note: 14 files is over the 10-file warning band; the tracer stays one slice because RoleKind must land on both DTOs, both templates, the adapter, the assembler, and the Phase 8 tests in the same round-trip.
