# Phase 9 Plan 02 — Persist port + fake + mapper

## Objective

Define the application-side persist contract (`PersistPort`, `PersistResult`), the local error taxonomy (`DraftPersistError`), the mapper to `IngestError(stage="persist")`, the slug/reading-minutes completion helpers, and an in-memory fake with a call spy. This wave produces the ingestion-service application layer and the test doubles that later waves will use to prove idempotency and overflow without a database.

Purpose: Lock the persist interface and error mapping before introducing Supabase-specific code.
Output: `PersistPort`, `PersistResult`, `DraftPersistError`, `map_persist_error`, `FakeDraftPersister`, `persist_draft` use-case, and `material_completion` helpers.
Scope note: 16 files and 3 tasks stay together because PersistPort, the fake, the mapper, MaterialDraft completion fields, and persist_draft are one contract; splitting would leave the use-case untestable against the port it owns.
