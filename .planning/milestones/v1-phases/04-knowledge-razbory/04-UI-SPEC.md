## Page & Component Contracts

### AppShell nav — D-66
- Add nav item **«Разборы»** → `/razbory` after **«Голосование»** (design-frontend order: Выпуск · Архив · База · Голосование · Разборы).
- Active state uses existing accent pill chrome.
- Do **not** add Admin nav this phase.

### Knowledge (`/knowledge`) — KNOW-01…04, D-57…D-65
- **Search trigger:** visible **«Найти»** + Enter/Submit only — **not** on every keystroke (D-57). Live-as-you-type out of scope (D-58).
- **Role filter:** chips **Analyst / DS / Все** replace role `<select>`; **remove** tag / format / topic selects (D-62, D-63).
- **Chip change:** if query is non-empty (trimmed), **re-run search immediately** (D-64); if query empty, only update chip state (no search).
- **Pre-search landing:** neutral empty + **topic hint chips** that fill the input (D-60). Hints do not execute search by themselves — user still presses «Найти» or Enter **[assumption: fill-only keeps Submit as single intentional trigger]**.
- **Hit row:** reuse/evolve `MaterialListRow` — cover (optional/null ok), title, tags, **chunk snippet**; **never** show score (D-59). Link → `/materials/{slug}`.
- **Pagination:** API top-N + **«Показать ещё»** when `has_more` (D-61). Default page size **10** **[assumption: RESEARCH A1]**.
- **Whitespace-only:** inline «Введите запрос»; no request (KNOW-01).
- **Zero hits:** honest empty + «Сбросить фильтр» clears **role only** (D-65). Never inject other-role tops.
- **Errors:** page GET N/A (search is mutation-like); search 5xx → banner + Retry with query kept; full ServiceUnavailable only if planner wires a blocking initial dependency.

### Razbory list (`/razbory`) — RAZB-01, D-66…D-69
- H1 «Разборы» + caption.
- Rows = **chronology-item** pattern (D-67): overline `date · status`, title (display/subhead), byline, ghost CTA «Читать разбор →».
- **Byline:** constant **«Редакция Digest CDS»** (no author column in schema) **[assumption: RESEARCH Q3]**. Optional DS role-badge if DTO provides role; omit when absent.
- **Announcement** rows: overline includes **«Анонс»**; still navigable to stub detail (D-68).
- **Empty list:** «Разборов пока нет» + **«К голосованию»** → `/voting` only (D-69).
- Order: newest meeting/created first (backend); UI does not re-sort.

### Razbor detail (`/razbory/:id`) — RAZB-02…04, D-68…D-73
- Back link «← Все разборы».
- **Announcement stub:** title + date + «Анонс» status + pending note «Полный разбор ещё готовится — следите за обновлениями.»; **no** prose column, **no** TOC, **no** metrics, **no** notebook strip pretending content exists (D-68).
- **Published longread:**
  - Reading layout = MaterialPage pattern: prose column + sticky TOC at `lg:`; mobile `<details>` «Содержание».
  - **Notebook dual action strip** (D-71): (1) top `info-banner--with-action` with «Скачать .ipynb»; (2) repeat download control near end / editorial-box. Download only — no in-app viewer (D-70).
  - Missing notebook: strip remains; control **disabled** + caption **«Notebook скоро будет»** (D-72). Failure toast «Не удалось скачать».
  - **Metrics honesty (D-73):** `content_kind=quality` → render «Качество» block + TOC entry when present in body; `content_kind=overview` → badge **«Обзор»**, omit metrics section entirely — never an empty table stub.
- **Soft 404:** calm «Разбор не найден» + «К списку разборов» (no splash art).
- **Page GET failure:** ServiceUnavailable + Retry (carry-forward).
