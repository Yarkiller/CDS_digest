> The design system is **already established and LOCKED** (`design-frontend/styles/*.css` + `web/src/index.css` Tailwind v4 `@theme`). Where a phase-specific detail was unspecified, the option consistent with the existing mockups/tokens was chosen and flagged **[assumption]**.

Locked OKLCH palette. 60/30/10 discipline mapped to existing tokens.

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--color-paper` / `--color-bg-surface` | oklch(97% 0.012 95) / oklch(98.5% 0.009 95) | App background, page canvas, prose surface (`--color-bg-prose`) |
| Secondary (30%) | `--color-paper-2` / `--color-bg-muted` | oklch(93.5% 0.018 95) | Archive cards (`issue-cover` on `bg-surface` + hover `bg-callout`), tag-pill background, editorial-box background, nav hover, muted meta zones |
| Accent (10%) | `--color-accent` | oklch(52% 0.13 278) (violet) | See reserved list below |
| Accent (voting) | `--color-voting` | oklch(62% 0.14 38) (warm orange) | **EditorialCallout only** — border + open-state emphasis. Not a general accent. |
| Destructive | `--color-danger` | oklch(48% 0.15 25) | ErrorPanel border/text only. No destructive user actions exist this phase. |

**Accent (`--color-accent`) reserved for — explicit list, never "all interactive elements":**
- Text links inside prose and meta (`a`)
- Active nav item background (`AppShell` NavLink active) + brand wordmark
- Primary/ghost CTA text ("Выбрать тему →", "К текущему выпуску", "← К выпуску")
- IssueTOC row hover title color + row hover surface (`bg-callout`)
- Section-TOC active link (material page)
- Tag-pill text (`#tag`)

**Callout state colors:**
- Open cycle: `--color-bg-callout` (oklch 94% 0.025 278) fill + `--color-voting` border, active CTA present.
- Closed cycle: **muted** — same border token at reduced emphasis or `--color-border`, `--color-text-secondary` body, **no CTA**. [assumption: reuse `--color-bg-muted` fill for the muted/closed state to visually de-emphasize vs the open violet-tinted fill.]

Do not introduce new hues. Error splash art `bad_gateway.png` is grayscale line art on white and sits inside the paper canvas — no color token needed for the image itself.

## Copywriting Contract

All copy is **Russian**, calm editorial tone (warm paper, no glow/gamification). **Never** show HTTP codes or stacktraces on screen (D-23). Domain terms: выпуск, материал (= подготовленная статья), цикл голосования, разбор.

|---------|------|
| Primary CTA (voting callout, open) | **«Выбрать тему →»** → `/voting` |
| Callout body (open) | «**Голосование открыто** до {дата окончания} — выберите тему следующего разбора.» |
| Callout body (closed) | «**Голосование закрыто.** Итоги появятся в ближайшем разборе.» — no topic-select CTA (D-35) |

| Empty archive heading | **«Архив пуст»** |
| Empty archive body + CTA | «Прошлых выпусков пока нет.» · primary CTA **«К текущему выпуску →»** → `/` |
| Archive → current backlink | **«← К текущему выпуску»** → `/` (always present on `/archive`, D-28) |

| Issue soft-404 heading (unknown/unpublished number) | **«Выпуск не найден»** (calm; error_handling §2.2 / RESEARCH Q1 RESOLVED) |

**Honesty rules (locked):**
- Audit-dek: render 1–2 audit-language sentences when present; **hide the dek block entirely when empty** — no stub sentence (D-36, ISSUE-03).
- Tags / provenance / related links / audit-dek: render **only what the API returns**; omit empty sections; **never fabricate** a related link (D-37, MAT-03).
- Material body = `body_markdown` → prose HTML; **no raw video/audio/transcript** shown as content (D-38, MAT-01).

**Destructive actions:** none in this phase. No confirmation dialogs required.

## Page & Component Contracts

### Issue page (`/` current, `/issues/:id` past) — ISSUE-01/02/03, US-03/04/05
- **Typography-only hero** (D-26): overline `Выпуск №{n} · {период}` → Display title → caption `{редакция} · {N} материалов`. **No cover image**, no `cover_url`.
- `hr` rule (`--space-8` margins) separates hero from body.
- **EditorialCallout** (`EditorialCallout.jsx`): rendered **only on current `/`** (D-34) — never on past `/issues/:id`. Open vs closed driven by read-only cycle DTO (D-33); Phase 2 is an honest stub, no vote write (D-32).
- **IssueToc** (`IssueToc.jsx`): list of materials — mono position number, display title, meta `{format} · {мин}`, `→` glyph, dek line below (hidden if empty). Each row → `/materials/:id`, min 44px target.
- **Empty issue** (0 published materials): empty-state block (`empty-state` pattern — H2 + one sentence + one primary CTA), copy above. Not a broken blank page (US-03.2).
- Past issue at `/issues/:id` reuses the **same IssuePage layout** (D-29), minus callout.
- **Unknown/unpublished issue number** (error_handling §2.2 / RESEARCH Q1 RESOLVED): calm soft empty «Выпуск не найден» + CTA «К текущему выпуску →» → `/` — **no `bad_gateway.png`** (distinct from network splash).
### Material (article) page (`/materials/:id`) — MAT-01/02/03, US-07/08/09
- Reading layout: **prose column** (`prose--column`, `--container-reading` max width, `--space-12` padding) + **section TOC generated from `body_markdown` headings** (D-38, MAT-01). Desktop: sticky side TOC (`--toc-width`); mobile: collapsible `<details>` "Содержание" at top.
- Header: format overline `Статья · {tag}`, Display title, byline caption `{дата} · provenance: {источник} · ~{N} мин`, `hr`.
- **«Статья» badge** always visible (MAT-03); **provenance, tags, related links shown only when present**, sections omitted when absent (D-37).
- **Audit-dek**: shown under title when present; **block hidden entirely when empty** (D-36).
- Tags render as `tag-pill` → `/knowledge`. Related-term internal links inline at first mention; never fabricated when target missing.
- TOC click scrolls/anchors to section (US-07.2).
- **Soft editorial 404** for unknown/unpublished/draft id (D-39, US-08.3, error_handling §2.3): calm heading + body + back-nav to issue/archive. **No `bad_gateway.png`**, no red panic UI.

### Archive (`/archive`) — ISSUE-04, US-28
- New route + **AppShell nav item «Архив»** (D-28) added between «Выпуск» and «База».
- Page title H1 «Архив выпусков».
- Grid of **past published issues only** (excludes current — D-31), each an `issue-cover` card (overline `Выпуск №{n}`, H2 period title, caption `{N} материалов`). Card → `/issues/:id`, opening the same IssuePage layout (D-29).
- Persistent **«← К текущему выпуску»** link → `/` (D-28).
- **Empty archive**: empty-state with CTA to `/` (D-30, US-28.2).

### Page-level load failure (ErrorPanel + splash) — D-21..D-23, error_handling §1.3/§2.2/§2.3/§2.8
- Trigger: issue/material/archive fetch fails (network / timeout / 5xx). **Never** silently fall back to mock content (D-21).
- Presentation: friendly splash `bad_gateway.png` (cartoon kitten, «Упс. / Ошибочка вышла.») above friendly copy and a **«Повторить»** button. Reuse `ErrorPanel` styling/`role="alert"` semantics or a dedicated ServiceUnavailable component (structure is planner discretion).
- **Asset:** relocate `bad_gateway.png` from repo root into `web/public/` (served as `/bad_gateway.png`).
- **Image spec:** centered, `max-width: 360px` on mobile / up to `420px` desktop, intrinsic aspect ~16:10 (~1000×639), `width`/`height` set to avoid layout shift, `loading="eager"`. **alt text:** `«Котёнок: ошибочка вышла»` (meaningful but non-technical). [assumption: 360–420px cap — the art is light line-art and must not dominate the paper canvas.]
- **Retry button** placement: directly **below the copy**, horizontally aligned with the splash (centered block), min 44px target, idempotent retry with disabled+spinner during request (§1.3).
- Copy under art: heading «Ошибочка вышла», body «Не удалось загрузить. Проверьте соединение и попробуйте ещё раз.» — **no HTTP status, no stacktrace** (D-23).
