# 26-REVIEW-DISPOSITION — что закрыто и что отложено

Ревью нашло 9 находок (1 critical, 5 warning, 3 info). Закрыт **CR-01** — единственная
находка, которая была регрессией, привнесённой самой фазой (до 26-02 её не существовало),
и единственная, воспроизводимая на текущем дереве живым URL. Остальные восемь записаны
`deferred` с причиной ниже; ни одна из них не является регрессией относительно состояния
до фазы.

## Fixed

### CR-01 — ручное сравнение `pathname` потеряло семантику `NavLink`

`26-02` перевёл три секционных пилла с `NavLink` на `<Link>`, потому что `NavLink` затирает
явный `aria-current`, когда его собственный маршрут неактивен — без этого маркер состояния
нельзя было объявить. Вместе с `NavLink` ушёл и `matchPath`, а на его место встало
`pathname === '/archive'` / `=== '/knowledge'` / `=== '/'` и `pathname.startsWith('/issues/')`.
Строковое равенство не нормализует ни хвостовой слэш, ни регистр, а маршрутизатор — да:

| URL | страница | пилл до фикса | пилл после фикса |
|---|---|---|---|
| `/archive` | Архив | Архив `page` | Архив `page` |
| `/archive/` | **Архив** | **ни одного** | **Архив `page`** |
| `/Archive` | **Архив** | **ни одного** | **Архив `page`** |
| `/knowledge/` | **База знаний** | **ни одного** | **База `page`** |
| `/Knowledge` | **База знаний** | **ни одного** | **База `page`** |
| `/issues/13/` | выпуск | Архив `true` | Архив `true` |

Дефект достижим вставкой ссылки с хвостовым слэшем (обычный артефакт копирования) или
капитализацией — и это ровно тот класс «шапка погасла», который фаза существует чинить.

Закрыто возвратом к роутеру вместо ручного сравнения — второго способа матчить маршруты
не заводится:

```jsx
const homeRoute = Boolean(matchPath({ path: '/', end: true }, pathname))
const archiveRoute = Boolean(matchPath({ path: '/archive', end: true }, pathname))
const issuesBranch = Boolean(matchPath({ path: '/issues/:number' }, pathname))
const baseRoute = Boolean(matchPath({ path: '/knowledge', end: true }, pathname))
```

TDD-пара, как требует `.cursor/rules/tdd.mdc`:

- `3deca26` — `test(26-04)`: `C-15b` рядом с `C-15`, `goto('/archive/')`, `goto('/Archive')`,
  `goto('/knowledge/')`, `goto('/Knowledge')` → `aria-current="page"`. Прогон дал **1 failed**
  на первом же кейсе (`Received: null` на живом `<a href="/archive">`), то есть RED по
  ожидаемой причине, а не по ошибке селектора.
- `92be6ce` — `fix(26-04)`: `matchPath` вместо равенства строк. `C-15b` → **1 passed**.
