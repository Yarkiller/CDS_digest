# Phase 26 — UI Design Contract

> Визуальный и поведенческий контракт для фронтенд-фазы. Сгенерирован gsd-ui-researcher, проверяется gsd-ui-checker.

Источники: `26-CONTEXT.md` (D-01…D-11 — locked), `.planning/ROADMAP.md` § Phase 26 (критерии 1-5), `.planning/REQUIREMENTS.md` (NAV-01, NAV-02), живой код `web/src`.

Фаза — **починка двух дефектов, а не новый UI**: ни одной новой строки копирайта, ни одного нового токена, ни одной новой раскладки. Всё, что контракт объявляет сверх существующего, — это два числовых значения (`scroll-padding-top`, мобильная `--header-height`), один атрибут (`aria-current`) и три литерала маркера (`'archive' | 'base' | 'issue'`).

| Property | Value |

## Spacing Scale

Объявленные значения кратны 4 (существующие токены `--space-*` в `web/src/index.css:95-105`):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Зазоры строчных глифов (существующее) |
| sm | 8px | Компактные отступы внутри пилюль (существующее) |
| md | 16px | **Воздух офсета якоря — единственное новое значение фазы (D-03)** |
| lg | 24px | Вертикальный ритм секций (существующее) |
| xl | 32px | Разрывы мажорных блоков (существующее) |
| 2xl | 48px | Высота поля поиска `min-h-12` (существующее) |
| 3xl | 64px | `--header-height` на `sm+` (D-02) |

Exceptions (все — существующие значения, не шаг шкалы; менять их в этой фазе запрещено):

- `--header-height`: хром-размер, а не шаг шкалы. `64px` на `≥640px` (locked, D-02); ниже `640px` — переопределение, **измеренное в браузере** и округлённое вверх до кратного 4 (ориентир ≈112px — оценка, не контракт; D-C1).
- `top-24` (96px) у липкой колонки «Содержание» (`MaterialPage`, `RazborPage`). Остаётся 96px даже при офсете 80px: пересчёт этого отступа сдвинул бы рейл, а это редизайн.
- Зазор офсета проверяется по живым прямоугольникам, поэтому расхождение между `--header-height` (64px) и фактической высотой шапки (по составу ≈73px: `min-h-12` поиска 48 + `py-3` 24 + `border-b` 1) не «чинится» правкой токена — D-02 фиксирует 64px. Ожидаемый остаточный зазор на десктопе ≈7px, а не 16px; это принятый результат, а не дефект.

## Typography

Фаза **не вводит ни одного нового размера и начертания**. Объявлены роли, которые реально рендерятся в затронутых поверхностях (значения — то, что уже дают утилиты Tailwind v4):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Проза статьи/разбора (`prose-column`, `leading-relaxed`) | 16px | 400 | 1.625 |
| Подпись пилюли шапки и ссылки «Содержания» (`text-sm`) | 14px | 400 | 1.43 |
| Заголовок-цель якоря `h2` (`text-2xl font-semibold`) | 24px | 600 | 1.33 |
| Подзаголовок `h3` (`text-xl font-semibold`) | 20px | 600 | 1.40 |

Итого: 3 размера (14 / 16 / 20-24) и ровно 2 начертания (400, 600). Заголовок-цель не получает ни `font-bold`, ни нового кегля: смена начертания при активном состоянии запрещена (см. C-18).

## Color

Ни один токен не добавляется и не меняется (THEME-01/02 закрыты в Phase 25). Значения — из `@theme static` и `[data-theme="light"]`.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-bg-app`: `#0B0F17` dark / `#F8FAFC` light | Фон документа и шапки |
| Secondary (30%) | `--color-bg-surface`: `#131925` dark / `#FFFFFF` light | Hover пилюли, карточка-дисклоуз «Содержание», поверхности списков |
| Accent (10%) | `--color-primary-solid` `#7C3AED` + `--color-on-solid` `#FFFFFF` | Только заливка активного пилла раздела |
| Destructive | `--color-danger-solid` `#DC2626` / `--color-danger-ink` `#F87171` dark, `#B91C1C` light | В этой фазе не используется |

Accent reserved for (закрытый список):

1. Заливка активного пилла «Выпуск» / «Архив» / «База», когда раздел заявлен (собственный маршрут, состояние или префикс `/issues/`).
2. Заливка уже существующего пилла «Админ» (WR-02) — не меняется.

Запрещено в этой фазе: акцентный цвет у заголовка-цели, у `:target`, у подчёркивания якоря, у рамки активного раздела, у любых новых маркеров. Подпись ссылок «Содержания» остаётся `--color-primary-text` (`#A78BFA` dark / `#6D28D9` light) как сейчас; неактивная подпись пилюли — `--color-text-secondary` (`#94A3B8` dark / `#64748B` light).

Не-цветовой сигнал активного раздела — атрибут `aria-current` (D-11). Иконки, подчёркивания и точки-индикаторы не добавляются: смена визуального языка навигации вне скоупа.

## Interaction Contract

Каждый пункт ниже — контракт, который обязан существовать в RED-виде до production-правки (`.cursor/rules/tdd.mdc`). «RED сегодня» = почему ассерт падает до фикса; «pin» = сегодня зелёный, но обязан остаться зелёным (характеризационный пин, защищает от регрессии).

### NAV-01 — офсет прокрутки

- **C-01. Один механизм, объявленный один раз.** В `web/src/index.css` появляется ровно одно правило `scroll-padding-top: calc(var(--header-height) + 1rem)` на `:root` (D-01/D-02). Запрещено: `scroll-mt-*` / `scroll-margin-top` на заголовках, `scroll-behavior: smooth` (новое визуальное поведение + недетерминизм ассерта), измерение высоты шапки в JS.
  - *Evidence:* `getComputedStyle(document.documentElement).scrollPaddingTop` на `/materials/rag-systems` при 1280×800 лежит в `[header.height + 1, header.height + 32]`.
  - *RED сегодня:* значение `auto` (парсить как 0) → ассерт обязан падать числом, а не `NaN`.
- **C-02. Короткая секция (критерий 1).** 1280×800, `/materials/rag-systems`: клик по первой ссылке в `getByTestId('material-toc')` → целевой `h2` целиком во вьюпорте, `gap = heading.top − header.bottom ∈ [1, 32]`.
  - *RED сегодня:* заголовок уезжает под шапку, `gap < 0`.
- **C-03. Длинная секция (критерий 2).** Фикстура с ≥6 заголовками и телом на ≥3 экрана (расширить `rag-systems` в `web/src/data/mock.js:61-68` или завести отдельный материал — правка тестовая, не production). Перед кликом явно проверить `heading.top > window.innerHeight` (иначе тест вакуумный), затем клик → тот же `gap ∈ [1, 32]` и заголовок во вьюпорте.
  - *RED сегодня:* цель под шапкой.
- **C-04. Телефон 390×844 (D-02, D-C1).** `details` «Содержание» раскрыт, клик по ссылке → тот же rect-критерий; **и** `getComputedStyle(document.documentElement).getPropertyValue('--header-height')` ≠ `64px`, а `scrollPaddingTop ≥ header.height + 1`.
  - *RED сегодня:* `scroll-padding` нет; при фиксе «только 64px» высота шапки на 390 больше офсета → `gap < 0`.
- **C-05. Граница breakpoint 639×844.** Тот же rect-критерий, плюс `scrollPaddingTop ≥ header.height + 1`. Ловит медиа-запрос с неверной границей (600px, `min-width` вместо `max-width`): при 639 навигация уже на второй строке, шапка высокая.
  - *RED сегодня:* нет офсета.
- **C-06. Разбор (D-05).** `/razbory/:id` (published longread с заголовками): клик в `getByTestId('razbor-toc')` → rect-критерий. Глобальное правило D-01 обязано покрыть разбор без правок `RazborPage.jsx`.
  - *RED сегодня:* тот же дефект, что в материале.

Измерение мобильной `--header-height` (D-C1, обязательный шаг, не «на глаз»): в браузере на `/` при 390×844 **и** 639×844 прочитать `document.querySelector('header').getBoundingClientRect().height`, взять максимум, округлить вверх до кратного 4 и записать значением (комментарием рядом с объявлением). Число не выводится из суммы паддингов.

Каскадная засада: `--header-height` объявлена внутри `@theme static`, то есть на `:root` в слое `theme`. Наивное `html { --header-height: 112px }` **проиграет** по специфичности (`:root` = 0,1,0 > `html` = 0,0,1) и тихо не применится. Переопределение объявляется на `:root` (та же специфичность, слой `base` идёт после `theme`), а результат доказывается C-04, а не порядком строк в файле.

### NAV-02 — активное состояние шапки

- **C-07. Форма состояния (D-07).** Ссылки передают `state: { section }`, где `section` — ровно один из `'archive' | 'base' | 'issue'`. Запрещено: путь происхождения (`{ from: '/archive' }`), номер выпуска в состоянии, `localStorage`/`sessionStorage`, вывод раздела из `pathname` для `/materials/:id`.
  - *Evidence:* матрица локаций ниже + отсутствие storage-API в диффе.
- **C-08. Архив → выпуск.** `/archive` → клик по карточке выпуска → `/issues/13`: пилл «Архив» имеет `aria-current="true"` и токены `bg-primary-solid` + `text-on-solid`; «Выпуск» и «База» — `aria-current` отсутствует (`null`) и заливки нет.
  - *RED сегодня:* `NavLink to="/archive"` не активен на `/issues/13`, атрибута нет.
- **C-09. Архив → материал.** `/archive` → `/issues/13` → ссылка «Содержания» выпуска (`IssueToc`) → `/materials/:slug`: «Архив» `true` + заливка, остальные два — ничего.
  - *RED сегодня:* после перехода не зажжён никто.
- **C-10. Текущий выпуск → материал (D-09).** `/` → `IssueToc` → `/materials/:slug`: «Выпуск» `aria-current="true"` + заливка; «Архив», «База» — ничего.
  - *RED сегодня:* ничего не зажжено.
- **C-11. База → материал.** `/knowledge` → строка `MaterialListRow` → `/materials/:slug`: «База» `true` + заливка, остальные два — ничего.
  - *RED сегодня:* ничего не зажжено.
- **C-12. Вторая стрелка цепочки.** Материал, открытый из архива → ссылка «Связанные материалы» (`MaterialPage.jsx:261`) → второй материал: «Архив» по-прежнему `true` + заливка.
  - *RED сегодня:* подсветка гаснет на втором переходе.
- **C-13. Прямой заход на материал (D-10).** Свежий контекст (`page.goto('/materials/rag-systems')` в новой странице, без `history.state`): ни «Выпуск», ни «Архив», ни «База» не имеют `aria-current` и заливки; «Голосование» и «Разборы» тоже не зажжены.
  - *pin:* сегодня проходит; ловит будущий шорткат «вывести раздел из URL». F5 внутри сессии намеренно сохраняет подсветку — это ожидаемое поведение, а не дефект.
- **C-14. Прямой заход на выпуск (D-10).** Свежий контекст `/issues/13`: «Архив» `aria-current="true"` + заливка (единственный раздел, выводимый из URL).
  - *RED сегодня:* атрибута нет.
- **C-15. Собственные маршруты (D-11).** `/` → «Выпуск» `page`; `/archive` → «Архив» `page`; `/knowledge` → «База» `page`; `/voting` → «Голосование» `page`; `/razbory` → «Разборы» `page`. Значение `page` — только для собственного маршрута, `true` — для заявленного состоянием/префиксом.
  - *pin:* сегодня зелёный; падает, если «унифицировать» всё на `true`.
- **C-16. Админ не задет.** `/admin/digest` и `/admin/materials/:id`: «Админ» `true` + заливка (WR-02), ни один из трёх разделов не зажжён, `section` в превью не передаётся.
  - *pin:* сегодня зелёный; ловит утечку маркера в админский маршрут.
- **C-17. Закрытый список (D-C4).** `state?.section` валидируется в `AppShell` против трёх литералов; значение вне списка = не зажжено ничего.
  - *Evidence:* статически — единственная точка чтения с тремя литералами; поведение невалидного значения — 🧪 backstop (см. UI Considerations).
- **C-18. Пилюля меняет только краску.** Набор классов «Архив» на `/archive` (активен) и на `/` (неактивен) отличается **ровно** парой `bg-primary-solid text-on-solid` ↔ `text-text-secondary hover:bg-bg-surface`; `min-h-11`, `rounded-full`, `px-2.5`, `text-sm` присутствуют в обоих. Сравнение — по разбиению на токены, не подстрокой (урок Phase 25: `bg-primary` — подстрока `bg-primary-solid`). В обеих темах computed fill `rgb(124, 58, 237)`, label `rgb(255, 255, 255)`; неактивная подпись `rgb(148, 163, 184)` dark / `rgb(100, 116, 139)` light.
  - *pin:* сегодня верно для NavLink-активного пилла; защищает от «подкрасим ещё и вес шрифта».
- **C-19. Офсет не задваивается.** В `web/src` нет `scroll-mt` / `scroll-margin` / второго `scroll-padding`; className проза-заголовков не приобретает `scroll-`. Существующий тест «keeps the material TOC as a desktop rail and a mobile disclosure» (`tests/web-app.spec.js:92-120`), включая проверку отсутствия горизонтального оверфлоу на 390, остаётся зелёным.
  - *pin:* сегодня ноль совпадений; после правки должно быть ровно одно — в `index.css`.

## Copywriting Contract

Фаза **не добавляет ни одной пользовательской строки**. Единственные новые данные в DOM — атрибут `aria-current` и `state.section`; они не отображаются.

| Element | Copy |
|---------|------|
| Primary CTA | отсутствует — фаза не вводит действий |
| Empty state heading | не применимо — «пустое» состояние фазы это отсутствие подсветки, текста у него нет |
| Empty state body | не применимо |
| Error state | не применимо — новых состояний ошибки нет; `ServiceUnavailable` и «… не найден» не меняются |
| Destructive confirmation | отсутствует — деструктивных действий в фазе нет |

Инварианты копирайта (проверяемо существующими локаторами):

- Подписи пиллов остаются байт-идентичными: «Выпуск», «Архив», «База», «Голосование», «Разборы», «Админ» — `getByRole('link', { name: /^Архив$/ })` продолжает находить ровно один узел.
- «Содержание» остаётся подписью и `summary` дисклоуза, и заголовком рейла; `aria-label="Содержание"` на `<nav>` не меняется.
- Запрещено добавлять «вы здесь», хлебные крошки, «← Назад в архив», бейдж раздела, `title`/`aria-label`, объясняющий происхождение: это новые навигационные элементы, вынесенные в Deferred.
