<objective>
Close the residual Phase 22 gaps that verification, UAT and code review left open, without touching the shipped 22-01/22-02 chrome contract: replace three human-only backstop truths with deterministic Playwright geometry assertions (GAP-BACKSTOP-1/2/3), suppress the spurious unsaved-changes dialog on an already-active section tab (WR-01), give the shell «Админ» pill a truthful `aria-current` and drop its dead `/admin` branch (WR-02, IN-04), restore a visually hidden `h1` outline on both admin surfaces (IN-01), and retire the vacuous employee assertion in favour of a real one (IN-03).

Output: three production-code deltas confined to `AdminLayout.jsx` and `AppShell.jsx`, seven new/rewritten Playwright cases in `tests/admin.spec.js`, and a green `tests/admin.spec.js` with the Phase 19 guard contract provably intact.

## Deferred gap — IN-02 (explicit, not silently dropped)

`tests/admin.spec.js:433` (`waitForTimeout(500)` in the G-14-2 test) is **deferred, not planned**. Reason: under `VITE_USE_MOCKS=true` the shortlist refetch is a mocked promise (`await delay(80)` inside `fetchShortlist`, `web/src/services/adminApi.js:239`) — it issues **no network request**, so `page.waitForResponse` cannot observe it; the page renders no busy/loading attribute while `mutating` is true (the only consumer is the mark-ready button that disappears, `AdminDigestPage.jsx:726`); and the harness exposes no shortlist-fetch counter (`web/src/main.jsx:54-64`). The only deterministic signal would be a new counter added to `web/src/services/adminApi.js` + `main.jsx` — production test-hook code in an unrelated, passing feature, outside this plan's file set; Playwright's fake clock would re-time React's scheduler and is a high flake risk. The current wait is a tracked Info finding in `22-REVIEW-DISPOSITION.md`; the follow-up recipe is: add `getMockShortlistFetches()` next to `getMockMarkReadyBatchCalls()` and `expect.poll` it above the pre-click count.
</objective>
