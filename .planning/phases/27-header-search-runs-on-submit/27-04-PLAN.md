<objective>
Close the input boundary and the render gates: a blank submission is a landing navigation that also clears the previous results, an overlong submission is an inline rejection with zero requests and no truncation, and the landing rule becomes a pure function of `qUrl` so hints can never coexist with a query.

Purpose: after plan 03 the URL drives everything, which means the URL can now also carry *invalid* and *empty* inputs into the page. This plan makes those three inputs (empty, whitespace, overlong) provable as zero-request outcomes, and pins the derived landing rule that the rest of the phase's assertions depend on.

Output: the empty-query reset branch, the overlong inline branch inside the effect, `preSearch` redefined on `qUrl`, and the boundary + landing + live-region cases in `tests/knowledge.spec.js`.
</objective>
