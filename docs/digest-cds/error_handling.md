Документ описывает **целевое** поведение продукта при негативных сценариях. Статический HTML-прототип часть контролов не реализует — ниже зафиксированы UX-решения для разработки.

## 1. Глобальные UX-паттерны

Стиль Concept 3: спокойный editorial UI (warm paper, serif/sans), без glow, glass и геймификации.

### 1.1 Валидация

| Правило | UX |
|---------|-----|
| Ошибка у поля | Текст под полем, `--color-danger`, `aria-invalid="true"`, фокус на первое ошибочное поле |
| Несколько полей | Показать все inline сразу; не блокировать остальной layout |
| Успех после исправления | Снять сообщение при blur/input, когда правило выполнено |
| Бизнес-правила (не формат) | Inline или inline-banner в форме («Цикл голосования закрыт») |
| Не использовать | Alert на каждое нажатие; красная заливка всей страницы |

### 1.2 Отсутствие данных (empty state)

| Правило | UX |
|---------|-----|
| Композиция | Serif-заголовок (H2) + одно предложение + один primary CTA (и опционально secondary) |
| Место | В колонке контента / prose-zone, не модалка |
| Без | Декоративных иллюстраций, emoji, «пустого» бесконечного skeleton |
| Загрузка | Короткий skeleton/placeholder строк списка; не путать с empty |

### 1.3 Сетевые ошибки

| Ситуация | UX |
|----------|-----|
| Offline / timeout / 5xx на чтении | Banner сверху main: «Не удалось загрузить. Проверьте сеть.» + кнопка **Повторить** |
| Offline / 5xx на мутации (голос, send) | Toast/banner: действие **не применено**; форма остаётся заполненной; **Повторить** |
| Частичный сбой (поиск) | Сообщение в зоне результатов + сохранить введённый запрос |
| Повтор | Идемпотентный retry; disabled + spinner на кнопке на время запроса |
| Без | Тихий fail; «успех» при фактически несохранённых данных |

### 1.4 Неавторизованный и запрещённый доступ

| Код / случай | Поведение | UX |
|--------------|-----------|-----|
| **401** нет сессии | Redirect на `login.html?returnUrl=…` | После входа — возврат на исходный экран |
| **403** роль не позволяет (не админ) | Страница «Недостаточно прав» | Текст: раздел только для CDS/делегата; CTA «На текущий выпуск» |
| Сессия истекла mid-action | Как 401 + сообщение «Сессия истекла» на login | Не терять черновик голоса/selection в `sessionStorage` при возможности |
| Чужой/несуществующий id | 404 editorial empty | «Материал не найден» + ссылка на выпуск / базу |

Копирайт: русский; термины **дайджест**, **цикл голосования**, **материал**, **исходный текст**, **разбор**, **shortlist**, **разрешённый домен** — по CONTEXT. Видео/аудио — только внешний источник обработки, не содержимое материала.

## 2. По ключевым функциям

### 2.1 Вход (`login.html`) — US-01, US-02

| Ось | Триггер | Система | UX | Действие пользователя |
|-----|---------|---------|-----|------------------------|

## 5. Примечания

1. **Прототип vs продукт.** В static Concept 3 часть кнопок (например «Предпросмотр письма») декоративна — целевое поведение задано в §2.7; см. также backlog C3-17/C3-18.
2. **Безопасность сообщений.** На login не раскрывать, существует ли email; для draft-материалов non-admin видит 404, не «нет прав на черновик».
3. **A11y.** Ошибки связаны с полями через `aria-describedby`; banner сети — `role="alert"`; focus management после redirect с login.
4. **Идемпотентность.** Повтор «Повторить» на голос/send не должен создавать дубликаты рассылки или двойной голос сверх правил цикла.
5. **Подготовка материала.** Ошибка транскрибации, импорта, дополнительного поиска или анализа не должна приводить к публикации сырого текста. До прохождения редакторского quality gate материал остаётся draft; внешняя ссылка на источник может сохраняться только как provenance.
