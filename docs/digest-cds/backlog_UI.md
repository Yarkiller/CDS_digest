# Реестр UI-замечаний — Digest CDS

Источник исходных замечаний: прогоны GhostUser MCP
(`run_agent_test`) от 2026-08-23 по статическим HTML-прототипам.
Канонический прототип находится в [`design-frontend/`](../../design-frontend/).

Статус на 2026-08-30: замечания C3-01…C3-18 закрыты в статическом
прототипе. Поэтому этот документ — реестр закрытия, а не список активных
дефектов. Закрытие подтверждено сопоставлением замечаний с текущими
HTML/CSS/JS-файлами `design-frontend/`; оно не заменяет production QA,
backend-интеграцию или проверку доступов.

## C3 — Editorial UI (закрыто в прототипе)

Путь: [`design-frontend/`](../../design-frontend/).
Проверенные экраны: `pages/issue.html`, `voting.html`, `knowledge.html`,
`material.html`, `razbory.html`, `razbor.html`, `admin-digest.html`.

### C3-01 · Заголовки материалов без audit dek — FIXED

**Severity:** LOW · **Тип:** CONTENT / UX · **Экран:** `pages/issue.html`

Заголовки материалов были понятны преимущественно DS-аудитории. В выпуск
добавлен короткий dek с объяснением пользы для СВА.

### C3-02 · Противоречивое состояние голоса — FIXED

**Severity:** HIGH · **Тип:** UX · **Экран:** `pages/voting.html`

Radio не выбран до действия пользователя, а лидер темы отделён от состояния
личного голоса. Статус «голос не отдан» больше не создаёт ложного выбора.

### C3-03 · Дефолтный RAG-запрос в базе знаний — FIXED

**Severity:** MEDIUM · **Тип:** UX · **Экран:** `pages/knowledge.html`

Поиск открывается в нейтральном состоянии без зашитого ML-запроса.

### C3-04 · Analyst-запрос возвращал только ML-выдачу — FIXED

**Severity:** HIGH · **Тип:** CONTENT / UX · **Экран:** `pages/knowledge.html`

В прототип добавлены отдельные материалы и ролевые признаки для SQL, BI и
качества данных; нерелевантная выдача не маскируется под ответ.

### C3-05 · ML-centric taxonomy — FIXED

**Severity:** HIGH · **Тип:** CONTENT · **Экран:** `pages/knowledge.html`

Таксономия дополнена ролями, темами и форматами для Data Analyst и Data

### C3-06 · Отсутствовали фильтры Role / Format / Topic — FIXED

**Severity:** HIGH · **Тип:** UX / IA · **Экран:** `pages/knowledge.html`

Добавлены компактные фильтры роли, темы и формата с сохранением понятного

### C3-07 · «Загрузить ещё» не менял выдачу — FIXED

**Severity:** MEDIUM · **Тип:** UX / QA · **Экран:** `pages/knowledge.html`

ролям.

## Production follow-up

Статический прототип подтверждает структуру экранов и ключевые состояния,
но не заменяет backend-интеграцию. Для production остаются отдельные
проверки:

- авторизация, `returnUrl` и 403 для админа;
- серверное сохранение голосов и правило «один голос на цикл»;
- авто-ранжирование и релевантность поиска;
- SMTP-рассылка, идемпотентная отправка и запись в архив;
- provenance, права доступа к `.ipynb` и серверная валидация предпросмотра.
