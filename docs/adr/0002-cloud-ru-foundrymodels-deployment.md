# Развёртывание на Cloud.ru и обработка через FoundryModels

Сервис Digest CDS разворачивается на виртуальной машине Cloud.ru. Обработка внешнего источника (получение/транскрибация текста из YouTube или импорт текста, суммаризация, анализ, тегирование, эмбеддинги для поиска и подготовка статьи агентом) выполняется через API FoundryModels Cloud.ru — не через публичные зарубежные API и не локальный Whisper на VM. Видео и аудио остаются внешним входом: они не сохраняются и не публикуются как материал, а в базе появляется только подготовленная статья и provenance-метаданные.

**Considered Options:** (A) Whisper on-prem; (B) публичные облачные API; (C) Cloud.ru VM + FoundryModels.

**Consequences:** весь стек и секреты живут в контуре Cloud.ru; зависимость от доступности FoundryModels; при смене провайдера потребуется адаптер для ML-pipeline. Pipeline должен уметь повторно получить текст или принять импорт, не превращая исходное видео/аудио в хранимый артефакт материала; перед публикацией статьи обязательны provenance, дополнительный поиск/анализ и проверка ссылок на связанные статьи.
