Разбор

RAG в корпоративной среде

14 апреля 2026 · Иван Петров · Data Scientist

Введение

Этот разбор демонстрирует минимальный RAG-пайплайн для поиска по регламентам СВА с использованием pgvector и FoundryModels для эмбеддингов.

Настройка окружения

pip install psycopg2-binary pgvector sentence-transformers

Индексация документов

Загружаем карточки знаний из базы, разбиваем на чанки и сохраняем эмбеддинги:

def chunk_document(text: str, size: int = 512) -> list[str]: words = text.split() return [" ".join(words[i:i+size]) for i in range(0, len(words), size)]

Гибридный retrieval

Комбинируем векторный поиск (pgvector) с полнотекстовым (PostgreSQL tsvector) через Reciprocal Rank Fusion. Веса fusion и метрики gold-set требуют подтверждения:

# RRF fusion (k=60) dense_w, sparse_w = 0.55, 0.45 score = dense_w / (k + dense_rank) + sparse_w / (k + sparse_rank) # Ablation (nDCG@10 на audit gold-set — метрики уточняются) # dense only: — | sparse only: — | RRF hybrid: —

Применение в аудите

Пример запроса: «Какие процедуры применяются при проверке IT-общих элементов?» Система возвращает релевантные фрагменты с цитированием источника. Precision@5 на таких запросах: метрика уточняется (см. таблицу выше).
